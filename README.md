# ✈️ Airline Customer Segmentation (Clustering Analysis) — Day 38

---

> ## 📦 Project Summary
>
> **Background**
> Industri penerbangan memiliki berbagai tipe pelanggan dengan perilaku yang berbeda. Tanpa segmentasi yang jelas, perusahaan sulit memberikan strategi layanan dan promosi yang tepat sasaran.
>
> **Objective**
> Melakukan segmentasi pelanggan maskapai menggunakan teknik clustering untuk mengidentifikasi pola perilaku pelanggan dan membantu strategi bisnis yang lebih efektif.
>
> **Approach**
>
> * Data preprocessing & feature scaling
> * Exploratory Data Analysis (EDA) untuk memahami distribusi data
> * Menggunakan **K-Means Clustering** untuk segmentasi pelanggan
> * Menentukan jumlah cluster optimal (Elbow Method)
> * Analisis karakteristik tiap cluster
>
> **Key Findings**
>
> * Teridentifikasi beberapa segmen pelanggan dengan karakteristik berbeda (high value, frequent flyers, low engagement, dll)
> * Pelanggan dengan frekuensi tinggi dan spending besar menjadi segmen paling valuable
> * Terdapat segmen pelanggan dengan aktivitas rendah yang berpotensi untuk diaktivasi kembali
>
> **Business Value**
>
> * 🎯 Segmentasi membantu personalisasi marketing campaign
> * 💰 Fokus pada high-value customers untuk meningkatkan revenue
> * 🔄 Strategi retensi dapat diterapkan pada pelanggan berisiko churn (low activity)
> * 📈 Optimalisasi layanan berdasarkan kebutuhan tiap segmen
>
> **Conclusion**
> Clustering memberikan insight yang kuat terkait pola pelanggan dan dapat digunakan sebagai dasar strategi bisnis berbasis data untuk meningkatkan customer engagement dan revenue.
>
> 📊 *Next Improvement:* Eksplorasi algoritma clustering lain (DBSCAN / Hierarchical) serta integrasi dengan model prediksi churn.
>
